# kdp-book

Fully-automated KDP book pipeline. From a single topic + book type, produces a
KDP-ready deliverable directory: print-interior PDF, wrap-cover PDF, EPUB, and
a `kdp.json` metadata package — with character-consistent illustrations
generated by `gpt-image-2`.

```bash
kdp-book generate --topic "The boy who loved chocolate" --type children-picture-book
kdp-book generate --topic "Reincarnated into a world of fantasy"  --type light-novel
kdp-book generate --topic "Python for beginners"                  --type non-fiction
kdp-book generate --topic "A detective haunted by her past"       --type fiction-novel
```

## Tech stack

- Python 3.11+ (`uv`-managed)
- Microsoft Agent Framework 1.2.0 (`@workflow`/`@step` + `FileCheckpointStorage`)
- Azure OpenAI: `gpt-5.5` (text + vision), `gpt-image-2` (images + edits)
- Pydantic v2 / pydantic-settings for typed I/O and config
- `reportlab` (KDP-compliant PDF), `ebooklib` (EPUB), `Pillow` (image post-processing)

